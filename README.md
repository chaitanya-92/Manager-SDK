# Manager SDK

A local-first terminal-style workspace for preparing branded KernelSU and KernelSU Next manager projects. The initial release validates project configuration and exports reproducible manifests; it does not build APKs or install a kernel engine. A single APK can manage an already installed, compatible and authorized engine; installing an APK on a stock phone does not create root.

Run `npm install` and `npm run dev` to open the workspace. Run `npm test` for configuration tests.
